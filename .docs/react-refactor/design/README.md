# Design System Documentation

Complete design system for the SAke E-Learning V3 React refactoring.

## 📁 Contents

This folder contains all design-related documentation:

### [STYLE_GUIDE.md](./STYLE_GUIDE.md)
**Complete design system with visual patterns**

**Contents:**
- Color palette (primary, secondary, accent, semantic)
- Typography scale and font families
- Spacing system (4px base unit)
- Border radius and shadows
- Component style patterns
- Animation and transitions
- Responsive breakpoints

**Key Features:**
- Maintains current visual appearance
- Design tokens with Tailwind CSS v4
- Component examples (Button, Card, MessageBubble)
- Migration strategy

---

## 🎨 Quick Reference

### Primary Colors
- **Primary Blue**: `#3b82f6` (brand)
- **Secondary Purple**: `#a855f7`
- **Accent Cyan**: `#06b6d4`

### Typography
- **Font**: Inter (sans), JetBrains Mono (code)
- **Scale**: xs (12px) → 4xl (36px)

### Spacing
- **Base Unit**: 4px
- **Scale**: 1 (4px) → 20 (80px)

---

## 📖 Usage

When designing new components:

1. Check [STYLE_GUIDE.md](./STYLE_GUIDE.md) for patterns
2. Use design tokens from Tailwind config
3. Follow component examples
4. Maintain consistency with existing UI
